# PUROnGSOFT Admin V01

ทางเข้า: https://purongsoft2026.github.io/purongsoft-admin/

สถานะ: เผยแพร่ Apps Script แยกและเชื่อมปุ่มเข้าสู่หลังบ้านแล้ว ยังไม่ได้ลงทะเบียน/เชื่อมร้านจริง
